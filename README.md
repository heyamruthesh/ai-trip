# ✈️ AI Trip Planner

An AI-powered web application that generates personalized travel plans based on user preferences such as destination, duration, budget, and trip type. Built using Next.js, this app helps users quickly plan efficient and customized trips.

---

## 🚀 Features
- Generate trip plans based on user inputs
- Supports multiple parameters:
  - Number of people
  - Current location
  - Destination
  - Number of days
  - Type of trip (Leisure / Budget)
- Clean and simple user interface
- Fast and responsive web app

---

## 🛠️ Technologies Used
- Next.js (React Framework)
- JavaScript
- HTML & CSS
- Vercel (Deployment)
